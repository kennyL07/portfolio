ESP32 Keychain || WIP

sep. 2026 - dec. 2026

About this project

I found this cool keychain online and I wanted to remake it for less than the $30

I used an esp32-waveshare that I had laying around from an impulse buy

This project is made using ESP-IDF for much of the firmware and TInyUSB for the file uploading

I was thinking about making an app or a local-website for fileuploading but that seemed like too much setup for something this small.
